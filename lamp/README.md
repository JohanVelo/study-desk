# Lamp

Lamp is a separate app that lives in this folder: a Bible reading and small-group study app for JJ's Bible study group. It is not part of Study Desk and shares no code or data with it.

- Live: https://johanvelo.github.io/study-desk/lamp/
- Accounts and group data: Supabase (sign-in with email and password, plus a group code).
- Built from a separate source; files here are the finished app.
